Permission Group Manager

The permissions of all user groups in one table – compare, copy and restore them in seconds.

Instead of opening the permission page of every user group, tick boxes in one matrix: rows are permissions, columns are groups. Compare groups, copy permissions between them, export and import groups and go back to earlier versions.

Features

Permission matrix

The same sections, order and translated labels as ResourceSpace's own group permission page, with the permission codes in a separate column.

Filters

Search permissions or groups, show only rows where groups differ or rows with unsaved changes, filter by parent group and page through many groups.

Copy between groups

Copy all permissions of one group to another in one step, then review the changes before saving.

Version history

Every save keeps the previous state. Load a version into the table to see the differences, or restore it at once.

Export and import

Move user groups and their permissions between sites as a file, choosing what to apply before the import.

Plugin and custom permissions

Sections for plugin permissions and your own permission codes with descriptions.

No lock-out

Your own group never loses Admin access or System setup access, and groups that inherit permissions are shown read-only.

Installation

In ResourceSpace

  1. Download the .zip above.
  2. In ResourceSpace open Plugin Manager > Upload a plugin and upload the file.
  3. Activate Permission Group Manager in the list of installed plugins, then open its Options.

Updating: upload the new .zip and choose Overwrite. Settings and data are kept in the filestore, outside the plugin folder.

On the server (command line)

# download and unpack – <RS_ROOT> is your ResourceSpace folder
cd /tmp
curl -fLO https://github.com/s29829/permission_group_manager/releases/download/v1.25/permission_group_manager-1.25.zip
# only when updating – the plugin data stays in the filestore
sudo rm -rf <RS_ROOT>/plugins/permission_group_manager
sudo unzip -q permission_group_manager-1.25.zip -d <RS_ROOT>/plugins/
sudo chown -R www-data:www-data <RS_ROOT>/plugins/permission_group_manager

www-data is the user that runs PHP (Apache on the RHEL family: apache). Then activate the plugin in System > Plugins. With git: git clone https://github.com/s29829/permission_group_manager <RS_ROOT>/plugins/permission_group_manager
